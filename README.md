# Task Manager App

A simple task manager web application that helps you organize your daily tasks. Built using HTML, CSS, and JavaScript.

## Live Demo

Check out the live version here: https://68e4fe5522dc4bda5cf057d0--radiant-snickerdoodle-a10b42.netlify.app/

## Features

- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Filter tasks by status (All, Active, Completed)
- View statistics (total tasks, active tasks, completed tasks)
- Clean and simple user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Type your task in the input field
2. Click "Add" button or press Enter
3. Click the checkbox to mark task as complete
4. Click "Delete" to remove a task
5. Use filter buttons to view different task categories
